Your PostgreSQL backups exist. Have you ever restored them?

pgCellar is a control room on top of Barman. It tells you where your backups stand, how far back you can go, and it restores them every week to prove it.

What it does

Servers in a few clicks

You add a PostgreSQL server. The SSH key is generated and deployed, Barman is configured. No file to write by hand.

A checked configuration

pgCellar inspects the PostgreSQL configuration on the server and tells you the exact setting to change, with the value it expects.

A state that does not lie

Last backup, age of the last archived WAL, disk space, barman check verdict. Red when it is red.

A timeline per server

Full backups, WAL, and how far back you can go. You see the gap before you need it.

Restore to the moment you pick

You choose the date and time. pgCellar restores for real, into a folder or into a tar.gz archive you download.

A drill every week

A real restore, the database starts, checks run, a dated PDF report. Telegram, mail or webhook alerts, JSON API and /metrics for the rest.

The proof

A backup you never restored is a guess. I prefer proof.

Every week pgCellar really restores, checks that the database starts, and writes a dated report. You hand it to whoever asks.

NIS2, insurers, ISO 27001 auditors: they all ask the same question. "When did you last restore?" Here the answer fits on one page.

The public demo shows a real drill report.

How it is built

Files are the truth. Barman keeps its own files. What is mine fits in one pgcellar.yaml. Every change is a local git commit.

The interface and the API are only forms over those files. An admin with a text editor can do everything without pgCellar. That is on purpose.

One Go binary, or a Docker image. Barman is installed as is (GPL-3.0) and driven through its command line. I do not modify it, I do not import it. That is a product rule.

pgCellar is written with AI agents, under my direction. I decide, I test on real servers, every release goes through automated tests, a code review and a real restore.
