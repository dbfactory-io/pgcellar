PostgreSQL · Barman · auto-hébergé

Vos sauvegardes PostgreSQL existent. Les avez-vous déjà restaurées ?

pgCellar est une salle de contrôle posée au-dessus de Barman. Elle vous dit où en sont vos sauvegardes, jusqu'où vous pouvez revenir, et elle les restaure toutes les semaines pour le prouver.

Ce que ça fait

Des serveurs en quelques clics

Vous ajoutez un serveur PostgreSQL. La clé SSH est générée et déployée, Barman est configuré. Pas de fichier à écrire à la main.

Une configuration vérifiée

pgCellar contrôle la configuration PostgreSQL côté serveur et vous donne le paramètre exact à changer, avec la valeur attendue.

Un état qui ne ment pas

Dernière sauvegarde, âge du dernier WAL archivé, espace disque, verdict de barman check. Rouge quand c'est rouge.

Une ligne du temps par serveur

Les sauvegardes complètes, les WAL, et jusqu'où vous pouvez revenir. Vous voyez le trou avant d'en avoir besoin.

Une restauration à l'instant voulu

Vous choisissez la date et l'heure. pgCellar restaure pour de vrai, dans un dossier ou dans une archive tar.gz à télécharger.

Un exercice chaque semaine

Une vraie restauration, la base démarre, des vérifications, un rapport PDF daté. Alertes Telegram, mail ou webhook, API JSON et /metrics pour le reste.

La preuve

Une sauvegarde qu'on n'a jamais restaurée est une hypothèse. Je préfère une preuve.

Chaque semaine pgCellar restaure vraiment, vérifie que la base démarre, et écrit un rapport daté. Vous le donnez à qui le demande.

NIS2, assureurs, auditeurs ISO 27001 : ils posent tous la même question. "Quand avez-vous restauré pour la dernière fois ?" Ici la réponse tient sur une page.

La démo publique montre un rapport d'exercice réel.

Comment c'est construit

Les fichiers sont la vérité. Les fichiers de Barman restent ceux de Barman. Ce qui est à moi tient dans un seul pgcellar.yaml. Chaque changement est un commit git local.

L'interface et l'API ne sont que des formulaires sur ces fichiers. Un administrateur avec un éditeur de texte peut tout faire sans pgCellar. C'est voulu.

Un binaire Go, ou une image Docker. Barman est installé tel quel (GPL-3.0) et piloté par sa ligne de commande. Je ne le modifie pas, je ne l'importe pas. C'est une règle du produit.

pgCellar est écrit avec des agents IA, sous ma direction. Je décide, je teste sur de vrais serveurs, chaque version passe par des tests automatiques, une relecture et une vraie restauration.
